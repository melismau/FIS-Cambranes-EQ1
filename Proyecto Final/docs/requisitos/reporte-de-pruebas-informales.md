# Reporte de pruebas informales

**Objetivo de las pruebas:**  
El objetivo de las pruebas informales es evaluar la facilidad del uso, claridad de información y eficiencia de las funciones principales del prototipo, identificando errores, dificultades y patrones de interacción haciendo que se permita validar los requisitos del usuario y proponer mejorar al diseño de la interfaz.

**Número de usuarios:** 20

**Perfiles evaluados:** Estudiantes, usuario primerizo

**Contexto:**  
Se usó un prototipo para realizar las pruebas a usuarios de diferentes rangos de edad, teniendo en cuenta el público potencial (14 – 25 años).

**Indicadores medidos:**

- Tiempo
- Número de errores
- Número de clics
- Nivel de dificultad para el usuario (1 como muy fácil y 5 como muy difícil)
