# 📋 Pruebas de Usuario - Mayapprendo

## 1. Registro de cuenta
- El usuario, al entrar por primera vez a la aplicación, deberá registrarse con un correo y contraseña nueva.  
- Si el correo no es válido (ejemplo: `aaa@aaa`), se notificará en pantalla que el correo es inválido.

## 2. Inicio de sesión
- Si el usuario ya tiene una cuenta registrada, podrá dar clic en el botón de **Inicio de sesión**.  
- Ingresará su correo/usuario y contraseña.  
- Este proceso solo se puede simular, ya que no existe una base de datos.

## 3. Tutorial
- Una vez registrada la cuenta, la aplicación mostrará un tutorial con las funciones de Mayapprendo.  
- Si el usuario no es nuevo y no logra recuperar o iniciar sesión, existirá un botón de **Omitir tutorial** para continuar con las lecciones.

## 4. Lección
- Tras finalizar el tutorial, el usuario iniciará con la **lección de verduras**.  
- La aplicación dará una breve instrucción sobre cómo se pronuncian las verduras en lengua maya.  
- Resultados:
  - **70% - 100% correcto:** se mostrará “Aprobado”.  
  - **Menos de 70%:** se mostrará “No Aprobado, tienes que repetir la lección”.

## 5. Repetir lecciones
- Si el usuario obtiene un porcentaje de **69% o menos**, deberá dar clic en **Repetir lección**.  
- Podrá intentarlo las veces que desee.

## 6. Lecciones estructuradas
- El usuario puede acceder al apartado de **Lecciones**.  
- Podrá visualizar todas las lecciones disponibles en Mayapprendo, junto con su nivel de dificultad.

## 7. Consultar estadísticas
- En el apartado de **Estadísticas**, el usuario podrá ver:
  - Su progreso en las lecciones.  
  - Una racha diaria de inicio de sesión (solo aumenta si completa una lección al día).

## 8. Apartado de accesibilidad
- El usuario podrá ajustar:
  - Volumen de la aplicación.  
  - Notificaciones.  
  - Modo oscuro o claro.

## 9. Mascota interactiva
- El usuario podrá interactuar con la mascota **Balam** en el apartado de mascota.  
- Podrá comprarle ropa o comida usando la moneda del juego: **cacao**.  
- Al realizar una compra, la aplicación mostrará un botón de **Confirmar compra**.

## 10. Compras dentro de la aplicación
- El usuario podrá acceder al apartado de **Compras** o dar clic en la imagen de los cacaos.  
- Allí visualizará los diferentes paquetes de cacaos (cantidad y precio).  
- Para adquirirlos:
  - Se simula el pago con tarjeta de débito o crédito.  
  - Tras ingresar los datos, aparecerán los botones **Pagar** y luego **Confirmar compra**, para evitar errores.

## 11. Eliminar cuenta
- En el apartado de **Opciones de accesibilidad**, habrá un botón en rojo: **Eliminar cuenta**.  
- Al seleccionarlo, la aplicación mostrará un mensaje de confirmación.  
- Si el usuario confirma, se mostrará en pantalla:  
  - Texto: **“Cuenta eliminada”**  
  - Imagen: **Balam llorando**.
