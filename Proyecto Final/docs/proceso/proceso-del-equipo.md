## 🔄 Proceso de trabajo  

El equipo trabaja bajo la **metodología Scrum** para desarrollar una aplicación móvil.  

### 🧩 Roles del equipo  
- **Product Owner**  
- **Scrum Master**  
- **Documentador**  
- **Codificador**  
- **Técnica del repositorio en GitHub**  
- **Diseñadora UI/UX**  

### 🛠️ Herramientas utilizadas  
- **GitHub**  
- **GitKraken**  

### 📈 Flujo de trabajo  
- El proceso inicia con la **planificación del proyecto**, donde el Product Owner define el **backlog** y el Scrum Master organiza los **sprints**.  
- Se realizan **reuniones diarias** para seguimiento.  
- El área de **UI/UX** diseña **prototipos** que se validan antes del desarrollo.  
- Durante cada sprint:  
  - El **Codificador** implementa funcionalidades.  
  - La **Técnica del repositorio** gestiona ramas y revisiones en GitHub.  
  - El **Documentador** registra avances y decisiones.  
- Al finalizar el sprint:  
  - Se hacen **revisiones**, **retrospectivas** y **pruebas funcionales**.  
  - El **Product Owner** valida las entregas.  
- Finalmente, se realiza la **publicación de versiones** y se da **mantenimiento continuo** al producto.
